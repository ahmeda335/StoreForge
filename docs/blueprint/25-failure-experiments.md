# 25 — Infrastructure and Failure Experiments

Experiments turn "I think it's resilient" into evidence. Each one is run with load generated (k6 low rate) and the observability stack open. The result is written up with the template in [`docs/experiments/TEMPLATE.md`](../experiments/TEMPLATE.md) (expected vs. actual, detection, recovery, changes made).

Tools: `docker compose stop/pause/kill`, **Toxiproxy** (latency, timeouts, connection resets between app and PG/Redis/provider), WireMock (provider/webhook receiver behaviour), the fake payment provider's failure modes, `pg_sleep`/lock injection.

| # | Experiment | Should happen | Must NOT happen | Logs | Metrics | Traces | Recovery |
|---|---|---|---|---|---|---|---|
| 1 | **Kill PostgreSQL** (`docker compose kill postgres`) during checkout load | Requests fail fast with 503 (≤ pool timeout); readiness DOWN; workers back off | Hung threads; liveness failing → restart storm; half-written orders | ERROR `CannotGetJdbcConnection…` with requestIds, worker WARN "DB unavailable, backing off" | 5xx rate ↑, `hikaricp_connections_pending` ↑ then timeouts, readiness gauge | HTTP spans ending in error at the connection-acquire span | Start PG → pool revalidates → readiness UP → jobs resume. Verify: no orders without outbox rows |
| 2 | **Kill Redis** | Rate limiter falls back to local; cache bypassed; latency rises slightly | Login/checkout failing; auth rate limits disappearing entirely | WARN circuit opened (once, not per request) | `resilience4j_circuitbreaker_state`, cache hit ratio → 0, DB QPS ↑ | Redis spans absent/short-circuited | Circuit half-open → closed |
| 3 | **Delay payment provider** 15s (Toxiproxy/fake) | Provider call times out at 5s; payment `UNKNOWN`; customer sees "processing"; reconciliation resolves | Double charge on retry; DB TX held during the wait; pool exhaustion | WARN payment timeout with orderId | `payments_failed{reason=timeout}`, client-span latency histogram at timeout ceiling | Long `POST /payment_intents` client span, not nested inside a DB TX span | Reconciliation job sets final state |
| 4 | **Same webhook ×10** (outbound to our test receiver *and* inbound provider replay) | Receiver dedups by event id; inbound: 1 state change, 9 no-ops | Order PAID twice, 10 emails | INFO "duplicate provider event ignored" ×9 | `provider_events_duplicates_total` +9 | 10 short spans, 1 with DB writes | n/a |
| 5 | **Same payment callback twice concurrently** | Exactly one transition; other blocks on row lock then no-ops | Two `PaymentCaptured` events | — | duplicates counter | Two spans; one waits on lock | n/a |
| 6 | **100 concurrent purchases, 1 unit left** | 1 order; 99 × 422 insufficient_stock; stock 0; ledger consistent | Stock −1..−99; deadlocks; 500s | INFO 1 order placed | `orders_created_total` +1, `inventory_reservation_failures_total` +99 | Lock-wait time visible in UPDATE spans | n/a |
| 7 | **One tenant floods traffic** (10× others) | That tenant gets 429; others' p95 unchanged | Global latency degradation; shared pool exhaustion | WARN rate limited (sampled) | `ratelimit_rejected` ↑; other stores' latency flat | Traces from the noisy store show 429 quickly | Traffic subsides |
| 8 | **Worker crash mid-job** (`kill -9` during webhook batch) | Leases expire; jobs re-run; receivers see duplicates with the same event id (dedup) | Lost jobs; job stuck "RUNNING" forever | On restart: INFO "reclaimed N expired leases" | `jobs_oldest_age` spikes then recovers | Two attempt spans for the same job | Automatic via lease expiry |
| 9 | **Slow query** (drop an index / `pg_sleep` in a view) | `statement_timeout` cuts it; affected endpoint degrades; others OK | Pool starvation across all endpoints | WARN query cancelled (57014) | DB duration histogram p99 ↑ for one query name | One long JDBC span dominating | Recreate index; postmortem |
| 10 | **Stop the message broker** (when introduced) | Outbox grows in PG; HTTP unaffected | Lost events; HTTP 5xx | WARN relay publish failed, retrying | `outbox_unpublished` ↑ | Relay spans erroring | Start broker → backlog drains |
| 11 | **Expire reservations under load** (clock jump in fake clock) | Expired reservations released once; stock restored | Double release (stock > physical) | INFO released N | `inventory_released_total` | Sweeper spans | n/a |
| 12 | **Deploy during traffic** (rolling restart) | Zero failed requests (graceful shutdown + readiness) | 502s from the proxy | Shutdown sequence logs | Error rate flat | — | n/a |
